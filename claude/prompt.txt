### Database Schema

```sql
-- Glossary database: ~/.sagemtl/glossary.db

CREATE TABLE novels (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    author TEXT,
    source_url TEXT,
    source_language TEXT DEFAULT 'zh',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE glossary_entries (
    id INTEGER PRIMARY KEY,
    novel_id INTEGER REFERENCES novels(id),
    source_term TEXT NOT NULL,
    target_term TEXT NOT NULL,
    term_type TEXT,  -- character, item, location, technique, etc.
    notes TEXT,
    confidence REAL DEFAULT 1.0,
    auto_generated BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(novel_id, source_term)
);

CREATE TABLE global_glossary (
    id INTEGER PRIMARY KEY,
    source_term TEXT NOT NULL UNIQUE,
    target_term TEXT NOT NULL,
    term_type TEXT,
    notes TEXT
);

CREATE INDEX idx_glossary_novel ON glossary_entries(novel_id);
CREATE INDEX idx_glossary_source ON glossary_entries(source_term);
```

## Code Style Guidelines

### Python Style
- Use type hints for all function signatures
- Use dataclasses or Pydantic models for data structures
- Use async/await for I/O operations
- Follow PEP 8 with 100 character line limit
- Use ruff for linting

### Qt/PySide6 Style
- Separate business logic from UI (core/ vs ui/)
- Use signals/slots for decoupling
- Run long operations in QThread
- Use QSS for styling (or QML if chosen)

### Testing Style
- Use pytest with fixtures
- Mock external APIs in tests
- Aim for >80% coverage
- Test both success and failure paths

## Error Recovery

If you encounter errors during execution:

1. **Import Errors**: Install missing packages with `pip install <package>`
2. **Test Failures**: Fix the failing code before proceeding
3. **File Conflicts**: Backup existing files, then proceed with changes

### Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| PySide6 import fails | `pip install PySide6==6.6.0` |
| Argos models missing | Run model download on first use |
| Qt platform plugin missing | Set `QT_QPA_PLATFORM=offscreen` for tests |
| WeasyPrint errors | Install GTK dependencies (Windows: GTK3 runtime) |
