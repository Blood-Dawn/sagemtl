Manga typeset fonts
===================

Bundled fonts are added in Phase 5. Only permissive (OFL / CC0 / Apache) fonts
are shipped:

  - Comic Neue (SIL OFL)        -> default body text (ComicNeue-Bold.ttf)
  - Bangers (SIL OFL)           -> SFX / titles
  - Noto Sans CJK / Source Han  -> vertical CJK output

Users may drop their own fonts (e.g. Wild Words, Anime Ace) into this folder.
Those proprietary / non-commercial fonts are never bundled with SageMTL.
