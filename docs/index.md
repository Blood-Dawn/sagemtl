# SageMTL Documentation

Welcome to the SageMTL knowledge base. These pages summarize how to install,
configure, and operate the multi-tooling translation stack.

## Start Here

1. Follow the [Use](use.md) guide to bootstrap your environment and understand the
   common translation flows.
2. Dive into the [TUI](tui.md) and [CLI](cli.md) sections to learn about the
   interactive interfaces.
3. Automate larger workloads with the [Batch](batch.md) runner.
4. Customize your experience through the [Settings](settings.md) reference.
